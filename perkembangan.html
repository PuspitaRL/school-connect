Nah, aku sudah ketemu bagian yang memang membuat halaman ini terasa lambat. Penyebab utamanya Kode sekarang melakukan query seperti ini: Kalau punya 2 anak di kelas berbeda → query daily_lessons 2 kali secara berurutan Setelah itu setiap pembelajaran melakukan query users lagi untuk mencari nama guru Jadi kalau ada 2 kelas, minimal ada beberapa request Supabase yang harus selesai satu per satu. Aku ubah menjadi: 1 query untuk semua kelas anak sekaligus → 1 query untuk semua guru sekaligus Jadi Alif Tsaniyah dan Alif 'Ula tetap dipisahkan berdasarkan kolom kelas, tetapi tidak perlu mengambil datanya satu per satu. Aku tidak mengubah tampilan, menu, struktur kartu, atau fungsi lainnya. Ganti kode kamu dengan ini: Pembelajaran Hari Ini - School Connect
